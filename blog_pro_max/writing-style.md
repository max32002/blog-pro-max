# Writing Style Guide

## 語氣
- 直接精簡，每句有目的；不堆砌形容詞
- 有明確立場，避免「可能」「或許有幫助」等模糊說法
- 開頭直接切入，不寫「在這個快速變遷的時代⋯」

## 格式
- 標題只用 H1、H2
- 段落 2–4 句；清單每條 ≤20 字
- 圖片：`![ALT](placeholder-描述)`
- 連結：`[錨文字](完整URL)`
- 必須含至少 1 個內部連結佔位：`[相關文章](internal-link)`

## SEO
- H1 含核心關鍵字（全文唯一）
- 前 100 字帶入關鍵字
- Meta description：60–80 字（中文）

## 標點
- 全形標點：`，。：「」`
- 英文專有名詞保留原始大小寫（GPT、API、SEO）
- 數字/英文前後加半形空格：`使用 3 個步驟` ✓

## 禁用詞彙
值得注意的是 / 不可否認地 / 在這個日新月異的時代 / 顯而易見 / 毋庸置疑 / 筆者認為 / 相信讀者
